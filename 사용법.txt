압수수색영장신청서 작성기 — 사용법
개발자: 법무연수원 김상기

[이 도구를 만든 이유]
영장 작성 경험이 적은 초급 수사관들이 압수수색영장신청서 작성을 어려워하는 경우가 많아, 클릭 몇 번과 짧은 입력만으로
부담 없이 초안을 만들 수 있도록 개발했습니다.
이미 영장 작성 경험이 있는 수사관이라면, 이 화면을 거치지 않고 빈 양식(.hwpx)에 바로 작성하는 쪽이 더 효율적일 수
있습니다. 자신의 숙련도에 맞게 선택해서 사용하세요.

[시작하기]
1. 이 폴더 전체를 원하는 위치(바탕화면 등)에 압축을 풀어주세요.
   압축을 풀지 않고 "start.bat"만 꺼내서 실행하면 작동하지 않습니다. 폴더 전체가 함께 있어야 합니다.

2. 폴더 안의 "start.bat" 파일을 더블클릭하세요.
   - 검은 창(명령 프롬프트)이 뜨고, 몇 초 뒤 기본 웹 브라우저에 신청서 작성 화면이 자동으로 열립니다.
   - "Windows에서 PC를 보호했습니다"라는 파란 보안 경고가 뜨면, "추가 정보" 클릭 → "실행" 버튼을 눌러주세요.
     (인터넷에서 받은 실행 파일에 Windows가 기본적으로 띄우는 경고이며, 이 프로그램은 인터넷에 연결되지 않고 이 PC 안에서만 동작합니다.)

3. 검은 창에 "Node.js가 설치되어 있지 않습니다" 같은 안내가 뜨면,
   https://nodejs.org 에서 Node.js(LTS 버전 권장)를 설치한 뒤 start.bat을 다시 실행하세요.
   Node.js 설치는 이 PC에서 딱 한 번만 하면 됩니다.

[사용 방법]
1. 브라우저 화면에서 기관명, 문서번호, 죄명, 압수할 물건, 수색·검증할 장소, 범죄사실 등을
   클릭하거나 직접 입력하세요. 입력칸을 클릭하면 위에 짧은 안내 문구가 나타납니다.
2. 다 채운 뒤 화면 아래 "신청서 생성 (.hwpx 다운로드)" 버튼을 누르세요.
3. .hwpx 파일이 바로 다운로드됩니다. 이 PC에는 별도로 저장되지 않으니, 다운로드된 파일이 유일한 사본입니다.
4. 검은 창을 닫으면 프로그램이 종료됩니다. 계속 쓰려면 닫지 말고 그대로 두세요.

[꼭 확인할 점 — 보안]
- 화면 맨 위 "1. 피의자 인적사항"(성명·주민등록번호·직업·주거)은 실제 수사 정보입니다. 꼭 필요한 경우에만 입력하고,
  확실하지 않으면 비워둔 채로 생성한 뒤 오프라인 상태에서 한글 프로그램으로 직접 채워 넣는 기존 방식을 권장합니다.
- 인적사항을 입력한 경우, 다운로드된 .hwpx 파일 자체가 민감정보를 담고 있습니다. 이 파일의 보관·전달에 각별히 유의하세요.
- 이 프로그램은 인터넷에 연결되지 않으며, 입력한 내용은 이 PC 밖으로 전혀 전송되지 않습니다. 서버에도 별도로 저장하지 않습니다.
- 하단의 검사 청구란·기각취지란은 검찰·법원이 작성하는 영역이라 비워둔 채로 나옵니다. 그대로 두세요.

[문제가 있을 때]
- "신청서 생성" 버튼을 눌렀는데 오류가 나면, start.bat을 실행한 검은 창이 아직 열려 있는지 먼저 확인하세요.
  창이 닫혀 있다면 start.bat을 다시 실행한 뒤 브라우저 화면을 새로고침하세요.
